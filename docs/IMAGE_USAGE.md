## 4. Procesamiento

Los originales pesan entre 7 y 27 MB. **Jamás se sirven al navegador.** Servir uno solo
haría imposible cualquier objetivo de LCP.

### Estructura

```
/originales/                    ← FUERA de /public, nunca se sirve
    GA9.jpg  (8,6 MB)  … los 17 archivos intactos

/public/images/gaviota/
    hero/       hero-19-desktop.jpg      1400×1750
                hero-19-tablet.jpg       1024×1280
                hero-19-mobile.jpg        780×1040   ← recorte 3:4 propio
    editorial/  campaign-7.jpg           1600×2000
                ritual-15.jpg  ritual-7.jpg  ritual-16.jpg
                founder-1.jpg … founder-6.jpg
                story-2.jpg  bts-ga15.jpg
    community/  community-9.jpg  -11.jpg  -17.jpg  -18.jpg
    products/   aceite-anti-estrias.jpg  … (recortes de GA9)
```

Los originales se conservan **íntegros** en `/originales/`, excluidos de `next build` y de
git (LFS o almacenamiento aparte: 324 MB no van en un repositorio normal).

### Parámetros

| Uso | Ancho máx. | Calidad | Formato |
|---|---|---|---|
| Hero escritorio | 1400 px | 82 | AVIF → WebP → JPEG |
| Hero móvil | 780 px | 80 | idem |
| Editorial | 1600 px | 80 | idem |
| Packshot | 1200 px | 85 | idem |
| Tarjeta | 600 px | 80 | idem |
| Miniatura | 200 px | 75 | idem |

`next/image` genera los formatos modernos automáticamente. El preprocesado solo reduce
resolución y hace los recortes de dirección de arte.

## 7. Reglas de tratamiento

**Prohibido, sin excepciones:**

- Alterar facciones
- Modificar cuerpos, adelgazar o retocar siluetas
- Cambiar tonos de piel, aclarar u oscurecer
- Filtros agresivos, saturación alta, virados de color
- Deformar o estirar (`object-fit: fill` está prohibido)
- Recortar de forma que se corten cabezas o productos
- Superponer texto sobre rostros
- Usar imágenes de stock existiendo estas
- Sustituir modelos por ilustraciones

**Permitido:**

- Recortar respetando el punto focal
- Reducir resolución
- Convertir a AVIF/WebP
- Ajustes mínimos de exposición para uniformar (±5 %)
- Degradado sobre la zona **sin rostro** para legibilidad del texto

La diversidad de tonos de piel, texturas de cabello y tallas de estas fotografías es el
activo diferenciador de la marca. Cualquier retoque que la homogeneice destruye
exactamente lo que la hace valiosa.

## 8. Rendimiento

| Regla | Aplicación |
|---|---|
| `priority` | **Solo en el hero.** Ninguna otra imagen |
| `width` y `height` | Siempre, en todas → CLS 0 |
| `sizes` | Explícito en toda imagen responsiva |
| `loading="lazy"` | Todas menos el hero |
| `placeholder="blur"` | En editoriales y packshots |
| `fetchPriority="high"` | Solo el hero móvil |

```tsx
<Image
  src="/images/gaviota/products/aceite-anti-estrias.jpg"
  alt="Aceite Anti-Estrías Gaviota by Lia, frasco de 115 mL con gotero"
  width={600} height={750}
  sizes="(max-width: 640px) 50vw, (max-width: 1024px) 33vw, 25vw"
  className="object-cover"
  style={{ objectPosition: '50% 52%' }}   /* punto focal */
/>
```

**Presupuesto de imagen del home:** ≤ 450 KB en la primera pantalla, ≤ 1,8 MB en la página
completa tras carga diferida. Se verifica con Lighthouse en cada despliegue.
